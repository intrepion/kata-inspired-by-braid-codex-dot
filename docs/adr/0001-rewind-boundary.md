# Keep memories outside reversible time

The player's motion, death and blue world clock belong to a bounded snapshot history. Amber memories and bell activation live outside that history, so retrieving something in a deep vault and reversing out changes the future. Restarts clear both domains. This deliberate asymmetry supplies puzzle progress without nondeterministic physics or echoes that would complicate save recovery and visual readability.

The room-origin snapshot is retained when the recent-history window fills. This permits a final jump back to the origin instead of trapping a player who waits inside a vault. The total history remains bounded at 1,800 snapshots.
